# Dinolex

Vite + Vue 3 (Options API: data, methods, computed) + Tailwind CSS v4.

    npm install
    npm run dev

Folder layout:

    index.html, package.json, vite.config.js
    public/start-bg.jpg            start page background
    public/dino/*.webp             7 dino poses
    src/main.js, style.css, store.js, audio.js, App.vue
    src/pages/StartPage.vue, GamePage.vue
    src/components/Backdrop.vue, Dino.vue, BorderBeam.vue, StarButton.vue, Confetti.vue
